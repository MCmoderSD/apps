# AniLink-Downloader

[AniLink-Downloader](https://github.com/MCmoderSD/AniLink-Downloader) downloads and unpacks media from single or multipart archives (mostly RAR, optionally password protected).
Paste hoster links, it creates direct links with a [Debrid-Link](https://debrid-link.com/premium) account, downloads the archive parts, unpacks them with 7-Zip and sorts the video files into a folder per show.

Like JDownloader, but through Debrid-Link: the files always come from Debrid-Link and never directly from the file hoster.

Store the downloads on a dataset in a large storage pool, ideally next to your media files, not in an ixVolume.

A Debrid-Link API key is required. The web page has no authentication, do not expose it to the internet.
